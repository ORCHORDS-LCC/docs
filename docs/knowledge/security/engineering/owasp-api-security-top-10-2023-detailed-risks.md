The risks are API-specific, meaning they address threats unique to application
programming interfaces rather than general web application risks. The 2023 edition
reflects the evolving API threat landscape.

## The "API risk categories" pattern
The OWASP API Security Top 10 (2023) structures risks around API-specific categories:

1. **Broken Object Level Authorization (BOLA)** — unauthorized access to resources at
   the object level
2. **Broken Object Property Authorization (BOPA)** — unauthorized access to object
   properties/fields
3. **Broken Function Level Authorization (BFLA)** — unauthorized access to API
   functions
4. **Unrestricted Resource Consumption** — excessive resource usage leading to denial
   of service
5. **Broken Object Property Composition (BOPC)** — manipulation of object property
   relationships

The specific ten categories were not available in the fetched pages; the complete list
is available at the OWASP project site.
