# ISO/IEC 27014:2020 — Information Security Governance Guidance

**Issue:** Organizations lack guidance on governing information security aligned to
an international standard, leading to misaligned security objectives and poor
executive oversight.
**Date:** 2026-10-29
**Author:** ORCHORDS
**Status:** documented

## Symptom
ISO/IEC 27014:2020 provides guidance on governance of information security. The
corpus has 1 document on this axis. Organizations without reference to this standard
risk misaligned security objectives, poor executive oversight, and non-compliance
with frameworks referencing ISO/IEC 27000-family supplements.

## Root cause
ISO/IEC 27014:2020 "provides guidance on concepts, objectives and processes for the
governance of information security, by which organizations can evaluate, direct,
monitor and communicate the information security-related processes within the
organization." Published 2020-12, Edition 2, 13 pages, SC 27.

**Source:** ISO catalogue:
`https://www.iso.org/standard/74046.html`

## The "governance" concept
ISO/IEC 27014 defines governance of information security as the activities that an
organization's leadership undertake to evaluate, direct, and monitor information
security management to achieve stated objectives. The standard covers:

- **Concepts** — governance vs. management, roles and responsibilities (VERIFIED
  from catalogue scope)
- **Objectives** — aligning information security with organizational strategy (VERIFIED)
- **Processes** — evaluate, direct, monitor, and communicate (EDMC framework) (VERIFIED)

The standard applies to organizations of any size, sector, or structure.

## The "EDMC framework" pattern
ISO/IEC 27014 structures governance around four processes:

1. **Evaluate** — assess current and planned information security arrangements
2. **Direct** — provide strategy, policy, and resource allocation decisions
3. **Monitor** — track performance against objectives and compliance requirements
4. **Communicate** — ensure information flows between governance and management levels

This pattern is VERIFIED from the catalogue scope. The standard distinguishes
governance (board-level) from management (executive-level), a distinction critical
for organizational design.

## Gotchas
- ISO/IEC 27014 is about *governance*, not management. It does not prescribe specific
  security controls; it guides how leadership should oversee information security.
- Edition 2 (2020) supersedes Edition 1 (2013). The corpus should reference Edition 2.
- The standard is short (13 pages) but dense; it covers governance concepts, not
  implementation details.
