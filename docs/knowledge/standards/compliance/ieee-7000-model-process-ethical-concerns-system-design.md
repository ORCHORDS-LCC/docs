## The "ethical model process" concept
IEEE 7000-2021 provides a set of processes by which organizations can include consideration of ethical values throughout the stages of concept exploration and development. It establishes a model process that can be adapted to different types of systems and organizational contexts.

Key aspects from the IEEE catalogue:
- **Standard number:** IEEE 7000-2021
- **Title:** IEEE Standard Model Process for Addressing Ethical Concerns during System Design
- **Status:** Published (2021)
- **Family:** IEEE 7000 series (AI ethics, transparency, bias)

## The "stakeholder value mapping" pattern
The standard describes processes for identifying and mapping stakeholder values throughout the system lifecycle:
- Identifying all relevant stakeholders and their values
- Mapping ethical concerns to system design decisions
- Establishing feedback loops for ethical review
- Documenting ethical trade-offs and justifications
- Iterating on design based on ethical assessment

This pattern is critical for:
- Regulatory compliance (EU AI Act, US Executive Order on AI)
- Ethical AI development frameworks
- Corporate governance and accountability
- Public trust and social responsibility

## Gotchas
- IEEE 7000-2021 is about the *process* for addressing ethical concerns, not specific ethical principles.
- The standard applies to all system types, not just AI — though AI/ML systems are a primary use case.
- The full standard text is behind IEEE's paywall (typically $95-$100 for individual standards).
