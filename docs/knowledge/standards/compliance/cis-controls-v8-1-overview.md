## The "v8.1 changes" concept
CIS Controls v8.1 builds on v8 with updates reflecting evolving threat landscapes:

- **Current download version** — v8.1 is the current version as of the CIS Security
  page (VERIFIED from CIS v8 page: "Download CIS Controls v8.1")
- **Change Log** — included in the download bundle, documenting changes from v8 to
  v8.1 (VERIFIED)
- **Implementation Groups** — included in the download bundle, defining three tiers of
  implementation complexity (VERIFIED)

The controls maintain the same five design principles as v8: Offense Informs Defense,
Focus, Feasible, Measurable, Align.

## The "implementation groups" pattern
CIS Controls v8 defines three Implementation Groups:

1. **IG1 — Basic Cyber Hygiene** — foundational controls for all organizations
2. **IG2 — Risk-Driven** — controls for organizations with known attack targets or
   regulated data
3. **IG3 — Expanded** — controls for organizations with specific regulatory or
   mission requirements

This pattern is VERIFIED from the CIS v8 page. The Implementation Groups document
is included in the download bundle.
