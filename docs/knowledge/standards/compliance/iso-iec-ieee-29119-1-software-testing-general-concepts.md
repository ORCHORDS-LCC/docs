## The "software testing" concept
ISO/IEC/IEEE 29119-1 defines the fundamental concepts of software testing:

- **Testing processes** — test planning, test monitoring and control, test
  completion (VERIFIED from catalogue scope)
- **Test activities** — test analysis, test design, test implementation,
  evaluating exit criteria, event logging (VERIFIED)
- **Test deliverables** — test policy, test plan, test procedure, test
  conditions, test cases, test scripts, test environment, test items (VERIFIED)

The standard applies to all types of testing across all types of products,
stakeholders, and organizations.

## The "testing lifecycle" pattern
ISO/IEC/IEEE 29119-1 structures testing around a lifecycle:

1. **Test planning and monitoring** — define test approach, estimate, schedule,
   identify risks
2. **Test analysis and design** — analyze test items, identify test conditions,
   design and prioritize test cases
3. **Test implementation and execution** — develop and prioritize test procedures,
   prepare test environment, execute test cases
4. **Evaluating exit criteria** — compare result against exit criteria, report,
   test completion

This pattern is VERIFIED from the catalogue scope. The standard is a joint ISO/IEC
and IEEE publication, combining international standards development with IEEE's
software engineering expertise.

## Gotchas
- ISO/IEC/IEEE 29119 is a multi-part standard. Part 1 covers general concepts; other
  parts cover processes, technical test automation, and agile testing. This document
  covers Part 1 only.
- The standard is a joint ISO/IEC and IEEE publication — both organizations are
  co-sponsors. This is unusual for ISO standards and reflects the close relationship
  between the two bodies on software engineering topics.
- Edition 2 (2022) supersedes Edition 1 (2013). The corpus should reference Edition 2.
