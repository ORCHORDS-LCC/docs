# ISO/IEC 42003 — AI Management System Implementation Guidance

**Issue:** ISO/IEC 42003 is an under-development standard providing guidance on implementing ISO/IEC 42001:2023 (AIMS). It has no published version yet and is not in the corpus.
**Date:** 2026-10-28
**Author:** ORCHORDS
**Status:** documented

## Symptom
The corpus contains ISO/IEC 42001:2023 (the AIMS management system standard) but no document on ISO/IEC 42003, which is designed to guide organisations on implementing 42001.

## Root cause
ISO/IEC 42003 is still under development (stage 20.00 — Preparatory). It has not been published as an International Standard and therefore has no catalogue page with a purchase link. The official ISO/IEC JTC 1/SC 42 catalogue lists it at https://committee.iso.org/committee/6794475/x/catalogue/.

**Source:** ISO/IEC JTC 1/SC 42 catalogue:
https://committee.iso.org/committee/6794475/x/catalogue/

## The "implementation guidance" concept
ISO/IEC 42003 is titled "Information technology — Artificial intelligence — Guidance on the implementation of ISO/IEC 42001." It is designed to help organisations implement the requirements specified in ISO/IEC 42001:2023.

Key details from the catalogue:
- **Title:** Information technology — Artificial intelligence — Guidance on the implementation of ISO/IEC 42001
- **Status:** Under development (AWI — Approved Work Item)
- **Stage:** 20.00 (Preparatory)
- **Technical Committee:** ISO/IEC JTC 1/SC 42

## The "sibling standard" pattern
ISO/IEC 42003 is the implementation companion to ISO/IEC 42001:2023. While 42001 specifies the requirements for establishing, implementing, maintaining, and continually improving an Artificial Intelligence Management System (AIMS), 42003 will provide the practical guidance on how to implement those requirements.

This mirrors the pattern seen in other ISO management system families:
- ISO/IEC 42001: Specifies requirements (what to do)
- ISO/IEC 42003: Provides implementation guidance (how to do it)

## Verification
The ISO/IEC JTC 1/SC 42 catalogue at https://committee.iso.org/committee/6794475.html lists ISO/IEC 42003 at stage 20.00 (Preparatory). The status is "Under development" — it is NOT a published standard. The catalogue page at https://www.iso.org/standard/81230.html confirms ISO/IEC 42001:2023 is the management system standard that 42003 will guide on.

## Gotchas
- **Status is critical:** ISO/IEC 42003 is NOT published. It is at stage 20.00 (Preparatory) as an AWI (Approved Work Item). Do not cite it as a published standard.
- **No purchase link:** Unlike 42001 (CHF 225) and 42005 (CHF 181), there is no catalogue page with a price — because the standard does not yet exist for purchase.
- **Timeline unknown:** Stage 20.00 is the earliest stage after project registration. The standard could take years to reach publication (compare 42001's timeline: 2020-08 proposal to 2023-12 publication = ~3 years).
