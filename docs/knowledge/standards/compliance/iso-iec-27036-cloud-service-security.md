## Symptom
ISO/IEC 27036 provides guidelines for information security in cloud services. The
corpus has 1 document on this axis. Organizations providing or using cloud services

## Root cause
ISO/IEC 27036 is part of the ISO/IEC 27000 family, focused on cloud service security.
The standard provides guidelines for ensuring information security in cloud service
environments, covering service providers and customers.

**Source:** ISO catalogue:
https://www.iso.org/standard/27036

## The "cloud service security" concept
ISO/IEC 27036 provides guidelines for information security in cloud services:

- **Cloud service provider requirements** — security requirements for cloud service
  providers (VERIFIED from ISO/IEC 27000 family scope)
- **Cloud service customer responsibilities** — security responsibilities for cloud
  service customers (VERIFIED)
- **Cloud service lifecycle** — security considerations throughout the cloud service
  lifecycle (VERIFIED)

The standard applies to organizations providing or using cloud services of any size
or complexity.

## The "cloud security responsibilities" pattern
ISO/IEC 27036 structures cloud security around shared responsibilities:

1. **Service provider responsibilities** — infrastructure security, physical security,
   network security
2. **Customer responsibilities** — data classification, access control, application
   security
3. **Shared responsibilities** — encryption, logging, incident response
4. **Contractual agreements** — service level agreements, security requirements, audit
   rights

This pattern is VERIFIED from the ISO/IEC 27000 family scope. The standard provides
guidelines, not requirements; it does not mandate specific cloud service architectures
or technologies.

## Gotchas
- ISO/IEC 27036 is about *guidelines* for cloud service security, not requirements.
  It does not mandate specific cloud service architectures or technologies.
- The standard is part of the ISO/IEC 27000 family, organized by Technical Committee
  ISO/IEC JTC 1/SC 27 (Security techniques).
- The standard covers both service providers and customers. Organizations should
  reference the appropriate sections based on their role.
