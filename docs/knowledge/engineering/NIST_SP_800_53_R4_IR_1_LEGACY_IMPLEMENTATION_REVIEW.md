# Incident Response Policy and Procedures Legacy Implementation Review

## Reference

- Control: **ir-1 — Incident Response Policy and Procedures**
- Catalog: NIST SP 800-53 Rev. 4

## Statement



## Implementation review

1. Record whether the system is in the scope that still depends on the Rev. 4 baseline, and the reason.
2. Compare the Rev. 4 statement with the current Rev. 5 statement for the same identifier, and record any difference that affects the implementation.
3. Review the implementation evidence against the statement that actually applies.
4. Record the withdrawal plan and the date by which the legacy baseline will no longer be used.
5. Record the risk accepted while the legacy baseline remains in use.

## Review evidence

- the applicability record for the legacy baseline;
- the comparison against the current statement;
- the implementation evidence;
- the withdrawal plan and its owner.

## Limitations

A legacy baseline is retained for systems that have not migrated. It does not describe current requirements, and this review does not certify conformity to it.
