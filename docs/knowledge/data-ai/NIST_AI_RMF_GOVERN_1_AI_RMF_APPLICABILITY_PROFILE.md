# GOVERN 1 AI Rmf Applicability Profile

## Reference

- Function: **GOVERN_1 — GOVERN 1**
- Function family: GOVERN

## Function statement



## Applicability profile

1. Determine which AI systems, models, and data flows are in scope for this function.
2. Record the applicability decision and its reason for each in-scope system.
3. Review the function's outcome against the current system behaviour, not the intended behaviour.
4. Record the evidence that would demonstrate the function is operating.
5. Record the gaps, their owners, and the remediation dates.
6. Record the inherited or shared responsibility where a supplier operates part of the system.

## Evidence expectations

- the AI system inventory for the scope;
- the assessment record for the function;
- the gap list with owners;
- the exception record where a function is not applied.

## Limitations

This profile is derived from the published function. It does not assert that any AI system satisfies it, and it does not replace the assessment evidence.
