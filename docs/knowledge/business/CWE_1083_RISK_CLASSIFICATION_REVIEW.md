# Data Access from Outside Expected Data Manager Component Risk Classification Review

## Reference

- Weakness: **1083 — Data Access from Outside Expected Data Manager Component**
- Abstraction: Base
- Status: Incomplete

## Weakness description

The product is intended to manage data access through a particular data manager component such as a relational or non-SQL database, but it contains code that performs data access operations without using that component.

1. Record whether the weakness class is relevant to the systems and data in scope, and the reason.

3. Record the likelihood assessment and the evidence behind it.
