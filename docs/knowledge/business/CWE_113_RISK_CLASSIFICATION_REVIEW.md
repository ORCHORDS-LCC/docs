# Improper Neutralization of CRLF Sequences in HTTP Headers ('HTTP Request/Response Splitting') Risk Classification Review

## Reference

- Weakness: **113 — Improper Neutralization of CRLF Sequences in HTTP Headers ('HTTP Request/Response Splitting')**
- Abstraction: Variant
- Status: Incomplete

## Weakness description

The product receives data from an HTTP agent/component (e.g., web server, proxy, browser, etc.), but it does not neutralize or incorrectly neutralizes CR and LF characters before the data is included in outgoing HTTP headers.
