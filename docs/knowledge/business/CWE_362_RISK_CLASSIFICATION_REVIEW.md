# Concurrent Execution using Shared Resource with Improper Synchronization ('Race Condition') Risk Classification Review

## Reference

- Weakness: **362 — Concurrent Execution using Shared Resource with Improper Synchronization ('Race Condition')**
- Abstraction: Class
- Status: Draft

## Weakness description

The product contains a concurrent code sequence that requires temporary, exclusive access to a shared resource, but a timing window exists in which the shared resource can be modified by another code sequence operating concurrently.
